# INSID3 论文与代码理解实操

本仓库实现 INSID3 第 3.1 节中位置去偏后的跨图匹配，并提供合成数据测试、一个可验证的加分题和一份代码语义审核。输入均为已提取的特征；运行只需要 CPU、Python 3.10 或更高版本、NumPy 和 pytest。

## 论文与代码定位

定位与文档初稿先于核心函数编写完成。论文采用 [arXiv:2603.28480v1](https://arxiv.org/html/2603.28480v1)，作者代码固定为提交 [`0c165a10cf52ab91f335883d06260de86854adbe`](https://github.com/visinf/INSID3/tree/0c165a10cf52ab91f335883d06260de86854adbe)。

| 内容 | 说明 |
| --- | --- |
| 论文依据 | [第 3.1 节](https://arxiv.org/html/2603.28480v1#S3.SS1)公式（2）定义掩码区域的参考原型和目标相似度；公式（3）及后文描述从低语义特征中通过 SVD 估计位置子空间；公式（4）将参考和目标特征投影到该子空间的正交补。 |
| 作者代码依据 | [`models/insid3.py:246–271`](https://github.com/visinf/INSID3/blob/0c165a10cf52ab91f335883d06260de86854adbe/models/insid3.py#L246-L271) 的 `_build_positional_basis` 对 probe patch 归一化、按通道中心化并做 SVD；`_debias_features` 完成投影和再次归一化。[`predict_mask:136–158`](https://github.com/visinf/INSID3/blob/0c165a10cf52ab91f335883d06260de86854adbe/models/insid3.py#L136-L158) 说明原始特征归一化及参考原型的构造顺序；[第 285–286 行](https://github.com/visinf/INSID3/blob/0c165a10cf52ab91f335883d06260de86854adbe/models/insid3.py#L285-L286) 用目标去偏特征与参考原型计算相似度。 |
| 本仓库的理解 | 低语义 probe 提供位置干扰方向的估计。跨图比较前同时去除参考与目标的这些分量，可以减弱“坐标相近但语义无关”的虚假匹配。掩码定义参考概念，区域内去偏 patch 的均值经归一化形成参考原型。 |

论文给出数学主干，作者代码补充中心化和归一化的具体顺序。论文使用形状为 `(P, C)` 的矩阵，其通道方向来自右奇异向量；作者代码使用转置布局 `(C, P)`，因此取左奇异向量，两者对应同一通道子空间。作者该提交使用经过图像标准化的全零图像生成低语义特征，而论文公式（3）以高斯噪声图像表述；本题直接接收特征，不生成 probe 图像。

## 第一题：计算约定

`src/insid3_matching.py` 提供 `compute_debiased_similarity`。设 `N(x) = x / max(||x||₂, 10⁻¹²)`，对矩阵按行计算。

1. 将 probe 按行优先顺序展平为 `(P, C)`，先计算 `Z = N(probe)`，再计算 `E = Z - mean(Z, axis=0)`。
2. 对 `E` 做薄 SVD，取前 `r` 个右奇异向量为 `basis = B`，形状为 `(C, r)`。
3. 参考和目标均先逐 patch 归一化，再计算正交补投影，清理浮点舍入量级的残差后作 `N` 归一化。probe 的均值仅用于估计子空间，不从参考和目标中减去。
4. 对参考掩码选中的去偏 patch 求算术均值，清理相消产生的浮点舍入残差，再归一化得到 `reference_prototype`。
5. 将目标去偏 patch 与参考原型作内积，恢复目标网格形状，返回 `similarity_map`。不作温度缩放或 min-max 缩放。

返回值均为 float64 数组，键为 `basis`、`reference_prototype`、`similarity_map`。实现用分解形式计算投影，并以绝对值矩阵乘法估计各通道的数值尺度，不构造 `(C, C)` 的单位矩阵或投影矩阵。

| 边界 | 行为与依据 |
| --- | --- |
| `rank = 0` | 返回 `(C, 0)` 基，跳过 SVD 和投影；每个 patch 只归一化一次，掩码均值另行归一化，作为不去偏的匹配基线。作者执行零维投影时仍会重复一次 patch 归一化，二者在小于 epsilon 的输入上可能不同；此处采用明确的基线约定。 |
| rank 超出薄 SVD 维度 | `r = min(rank, Hp * Wp, C)`，与作者取奇异向量切片的上界一致。 |
| probe 秩不足 | 保留所请求切片中的零奇异值方向，与作者代码一致，不额外按数值秩截断。零奇异值空间和重复奇异值空间的基可能不唯一；不能将这些方向解释为已识别的位置信号。 |
| 全通道投影 | 当 `r = C` 时，正交补维度为零，直接返回零去偏特征，避免矩阵减法产生伪残差。 |
| 零向量或均值相消 | 精确零向量保持为零。投影残差和前景均值在归一化前进行相对于输入尺度的浮点误差检查；超过该容限的真实弱信号继续采用 epsilon 归一化，而不是统一按 `1e-12` 丢弃。 |
| 空掩码 | 抛出 `ValueError`，不制造参考原型。作者实现没有为所有参考均为空的情况提供可用原型；明确报错是本题的接口约定。 |
| 无效输入 | 特征必须是非空、三维、有限实数数组，通道数必须相同；掩码必须与参考网格对齐且仅含 0/1 或布尔值；负 rank 抛出 `ValueError`，非整数或布尔 rank 抛出 `TypeError`。 |
| 网格与输入所有权 | 三张特征图可分别使用不同的非方形网格；不修改输入，支持只读数组和非连续视图。 |

浮点误差检查逐通道进行：只有向量的所有分量均不超过各自 `8 × float64机器精度 × 运算尺度 + 32 × float64机器精度 × 行尺度` 时，才将整向量视为数值零。对投影，运算尺度为 `abs(X) + (abs(X) @ abs(B)) @ abs(B).T`，行尺度为归一化 patch 的最大绝对分量；对前景均值，二者分别为所选 patch 的逐通道绝对值均值和各 patch 最大绝对分量的均值。

逐通道项处理矩阵运算的消去误差，小的行尺度项处理基估计和此前归一化传播的舍入误差。容限不因增加空通道而扩大；测试同时覆盖 3 维和 768 维弱信号、旋转子空间及真实微小均值不平衡。这项工程容限会将误差量级内的信号视为不可分辨的数值零，不宣称保留任意微小的实数信号；它不是论文的额外语义阈值，与归一化的 `1e-12` 分母下限不同。

这项数值保护、边界校验和 float64 计算均属于本题的工程约定，作者原代码没有相同的残差清理分支。普通非退化输入仍按原流程计算，数值误差范围内的残差信号不作语义解释。这里不提取 DINOv3 特征，不下载权重，不进行聚类或完整分割，也不复现论文指标。

## 安装与测试

在仓库根目录创建环境并安装依赖：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

一条命令运行第一题全部测试：

```sh
.venv/bin/python -m pytest -q
```

Windows 环境将 `.venv/bin/python` 替换为 `.venv\Scripts\python.exe`。`pytest.ini` 将默认测试目录限制为 `tests/`，因为加分题的待答实现由后续受测模型提交。

测试覆盖位置子空间的通道维度、正交性与投影；probe 中心化和归一化顺序；位置干扰反例；掩码选择；投影后 patch 与区域均值的归一化顺序；rank、零向量、网格、非法输入及输入不可变性。复核补充旋转纯位置特征、随机满通道投影、旋转语义相消、真实弱残差保留、次正规数值及非退化输入的独立矩阵形式对照。数据由测试自行构造，数学预期独立于待测函数。

当前版本的实际运行结果（2026-09-10，本机 CPU）：

| Python | NumPy | pytest | 实际结果 |
| --- | --- | --- | --- |
| 3.12.13 | 2.5.3 | 9.1.1 | `67 passed in 0.08s` |
| 3.10.20 | 1.24.4 | 7.4.4 | `67 passed in 0.16s` |

复核中，将新增数值回归用例应用于原提交 `96c75fe` 时，旋转纯位置、满通道投影、旋转语义相消和次正规归一化四类检查均失败；修复后通过。回归也覆盖 768 维弱信号，避免数值保护因通道数增加而误删真实信号。耗时随机器和缓存变化。验证仅覆盖本题的数值流程和输入契约，不代表已运行完整 INSID3 分割或复现论文指标。

## 第二题：可验证的叶节点

- `bonus/bonus_task.md`：供受测模型阅读的题面，规定 `src/insid3_aggregation.py::aggregate_from_seed` 的接口。
- `bonus/bonus_design.md`：考点依据、错误假设、手算例子和判定方法。
- `bonus/test_bonus_task.py`：等待模型实现后运行的最小验证用例。

题目限定为固定种子后的聚类合并评分。受测模型无需实现特征提取、去偏、聚类或种子选择。本仓库不提交该题的参考实现，也不声称 GPT-5.5 已经失败。模型提交答案后运行：

```sh
.venv/bin/python -m pytest -q bonus/test_bonus_task.py
```

未放入答案时，该命令应明确失败并提示实现路径，不跳过，也不记为通过。用例自检已在独立临时目录完成：正确 float64、正确 float32、含延迟注解及 `dataclass` 与包内相对导入的三种临时答案，各通过 7 项测试；十二种典型错误实现均被识别，详情见设计说明。临时实现没有进入本仓库，也没有实际调用 GPT-5.5。分发评测题时仅向模型提供题面和约定资料；设计说明与验证用例由评测者持有。公开仓库本身不构成隐藏测试环境。
